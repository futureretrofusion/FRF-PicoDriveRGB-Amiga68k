## Future Retro Fusion AmigaOS 68k port

**Future Retro Fusion**

Porting and integration work in this branch includes:

- native AmigaOS 68k libretro host
- native HAM6 custom-screen output
- Direct CHIP dirty-UWORD presenter
- optional native ScreenBuffer page flipping
- AHI 44.1 kHz linked double-buffer transport
- interleaved audio-protection governor
- Amiga controller backends
- FRF Emu68 ARM coprocessor client and ABI integration
- PiStorm/Emu68 hardware validation and performance work
